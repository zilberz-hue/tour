# Tizon Tour – מדריך התקנה

אפליקציית ווב לניהול טיולים: מסלול יומי, תקציב והוצאות, הזמנות ומסמכים, רשימות ציוד ומשימות.
Vanilla JS + Firebase, פריסה ב-Netlify. עובדת בטלפון וניתנת להתקנה כאפליקציה (PWA).

## מצבי עבודה
- **מקומי (ברירת מחדל):** כל עוד `apiKey` ריק ב-`firebase-config.js`, הנתונים נשמרים בדפדפן בלבד. מגיע עם טיול קרמל כדוגמה.
- **ענן:** אחרי הדבקת config של Firebase – התחברות (Google / אימייל), סנכרון בין מכשירים, שיתוף טיול עם שותפים לפי אימייל, והעלאת קבצים (כרטיסים, אישורים).

## הפעלת ענן (פעם אחת)
1. Firebase Console → צור פרויקט חדש (למשל `tizon-tour`).
2. **Authentication** → Sign-in method → הפעל Google ו-Email/Password.
3. **Firestore Database** → Create database (Production mode).
4. **Storage** → Get started (לצירוף קבצים).
5. Project settings → Your apps → Web app → העתק את ה-config אל `firebase-config.js`.
6. Firestore → Rules → הדבק את התוכן של `firestore.rules` → Publish.
7. Storage → Rules → הדבק את `storage.rules` → Publish.
8. Authentication → Settings → Authorized domains → הוסף את הדומיין של Netlify.

## פריסה ב-Netlify
- **בלי מחירי טיסות חיים:** גרור את התיקייה ל-Netlify (drag-and-drop). כל השאר עובד.
- **עם מחירי טיסות חיים:** גרירה לא מעלה פונקציות. פורסים דרך Netlify CLI (`netlify deploy --prod`) או מ-GitHub.

## חיפוש חי בכל הספקים במקביל (search-all)
הפונקציה `netlify/functions/search-all.mjs` פונה לכל הספקים המחוברים בבת אחת, מאחדת כפולים ומסמנת: 💰 הכי זול · 🏆 הכי משתלם · ⚡ הכי מהיר.
כל ספק נדלק כשמוסיפים את המפתח שלו ב-Netlify → Site configuration → Environment variables:

| משתנה | ספק | מה מקבלים |
|---|---|---|
| `SERPAPI_KEY` | serpapi.com | Google Flights + Google Hotels – כל החברות וכל אתרי ההזמנות. 250 חיפושים בחודש חינם |
| `DUFFEL_TOKEN` | duffel.com | מחירים חיים וניתנים להזמנה מ-300+ חברות. $3 להזמנה |
| `TRAVELPAYOUTS_TOKEN` | travelpayouts.com | Aviasales – מאות חברות וסוכנויות (מחירים מחיפושים אחרונים). חינם, דורש אישור |
| `ANTHROPIC_API_KEY` | console.anthropic.com | יועץ AI (Claude) |
| `GOOGLE_PLACES_KEY` | Google Cloud | מסעדות ואטרקציות עם דירוג, מחיר ו״פתוח עכשיו״ |

הנוסחה ל״הכי משתלם״ בטיסות: מחיר + ₪60 לכל שעת טיסה + ₪150 לכל עצירה − ₪180 אם מזוודה כלולה. במלונות: דירוג × אמינות הביקורות ÷ מחיר.
השכרת רכב: אין כרגע API ציבורי שמאגד את כל החברות – הכפתור פותח את Kayak, Momondo ו-Expedia עם הפרטים ממולאים.

## הכל בעברית
- אתרים עם גרסה עברית נפתחים בה ישירות: Skyscanner, Google (טיסות, מלונות, מפות), Kayak ‏(he.kayak.com), Booking, Hotels.com, Agoda, Airbnb, TripAdvisor.
- אתרים בלי עברית (Expedia, Momondo, Kiwi, Yelp, OpenTable, GetYourGuide, Viator, Klook ועוד) נפתחים מתורגמים דרך Google Translate, עם קישור "מקור" אם התרגום מפריע להזמנה.
- במדריך הקולי: ערכי ויקיפדיה באנגלית מתורגמים אוטומטית לעברית, והקריין מקריא אותם בעברית.

## מדריך קולי
- הקראה דרך קול המכשיר (Web Speech). באייפון: הגדרות → נגישות → תוכן מוקרא → קולות → עברית (כרמית).
- מקומות קרובים: ויקיפדיה (עברית, ואנגלית כגיבוי). שירותים (דלק, סופר, שווקים וכו׳): OpenStreetMap. שניהם חינם וללא מפתח.
- תסריטי קריינות מוכנים לכל תחנות טיול קרמל, באובייקט `GUIDE` ב-app.js.

## עוד יכולות
- **מפה:** כל התחנות לפי ימים (צבע לכל יום), מועדפים ❤️, וקו נסיעה אמיתי (OSRM). מיקומים לא ידועים מאותרים אוטומטית (Nominatim).
- **זמני נסיעה:** בין כל שתי תחנות ובסך הכל ליום.
- **מזג אוויר:** Open-Meteo – תחזית עד 16 יום קדימה; לפני כן – אותם תאריכים בשנה שעברה. כולל שעת שקיעה.
- **Uber · Lyft · Waze:** בכל תחנה, מועדף ומקום במדריך – הזמנת נסיעה ליעד בלחיצה.
- **חלוקת הוצאות:** ״מי שילם״ ו״עבור מי״ בכל הוצאה/הזמנה; מסך ⚖️ חלוקה מראה מי חייב למי.
- **התראות מחיר:** 🔔 על טיסה/מלון → נבדק כל 6 שעות כשהאפליקציה פתוחה (דורש search-all), התראה בדפדפן כשיורד.
- **ייבוא מהמייל:** מדביקים אישור הזמנה – מזוהים ספק, קוד אישור, תאריכים ומחיר.
- **סיכום בוקר:** בדף הסקירה – מזג אוויר, שקיעה, תחנה ראשונה, נהיגה כוללת ולינה הלילה.
- **📅 השוואת תאריכים:** בטיסות ובמלונות – כפתור שבודק 3 ימים לפני ואחרי, באותו אורך טיול, ומציג לוח צבעוני (ירוק = זול). לחיצה על תאריך מחפשת בו. כל לחיצה = 7 חיפושים מול הספקים (שימו לב למכסת SerpApi).
- **ערכת צבע:** כפתור 🌗 בסרגל העליון – כהה, בהיר, או אוטומטי לפי הגדרות המכשיר (ברירת מחדל). הבחירה נשמרת לכל משתמש.
- **אופליין:** האפליקציה, הנתונים, המפה ואריחי מפה שנצפו נשמרים במכשיר.

## 🤖 יועץ AI אונליין
כפתור "יועץ AI" צף בכל מסכי הטיול. היועץ מקבל את כל הטיול (מסלול, הזמנות, תקציב, משימות, מזג אוויר) ועונה בעברית. הוא יכול:
- לחפש מחירים חיים (טיסות, מלונות, מסעדות, אטרקציות) דרך search-all
- להוסיף תחנה למסלול, משימה/פריט ציוד, או הוצאה – רק כשמבקשים
- לקבל שאלה בדיבור (🎤) ולהקריא תשובה (🔊)

שני מנועים, נבחרים אוטומטית:
1. **בתוך Claude** (הקישור של ה-artifact): עובד מיד, על חשבון ה-Claude של מי שפותח. בפעם הראשונה מופיעה בקשת אישור.
2. **ב-Netlify**: הפונקציה `netlify/functions/advisor.mjs`. מוסיפים `ANTHROPIC_API_KEY` (מ-console.anthropic.com) במשתני הסביבה. אופציונלי: `AI_MODEL` (ברירת מחדל `claude-sonnet-5-5`).

השיחה נשמרת במכשיר לכל טיול בנפרד (🗑️ = שיחה חדשה).

## מבנה הנתונים
אוסף אחד: `trips/{tripId}` – מסמך לכל טיול, עם `ownerId`, `members` (uid) ו-`inviteEmails`.
ימים, הוצאות, הזמנות ורשימות נשמרים בתוך מסמך הטיול.
